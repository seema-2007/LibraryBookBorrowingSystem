# Library Book Borrowing System

A simple console-based library management application developed using Java.

## Features
- Add new books
- View all books
- Borrow books
- Return borrowed books
- Check book availability

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner

## How to Run

1. Install Java JDK.
2. Open Command Prompt in the project folder.
3. Compile the program:

   javac LibraryBookBorrowingSystem.java

4. Run the program:

   java LibraryBookBorrowingSystem

## Sample Menu

1. Add Book
2. View All Books
3. Borrow Book
4. Return Book
5. Exit
